# Plateforme de Surveillance IoT

Application web de surveillance en temps réel développée avec Laravel.

## Fonctionnalités

- Surveillance des capteurs IoT
- Température
- Humidité
- Gaz
- Courant
- Puissance
- Alertes automatiques
- Dashboard administrateur
- Dashboard technicien
- Historique des mesures
- Graphiques temps réel

## Technologies

- Laravel
- MySQL
- Grafana
- MQTT
- Bootstrap
- PHP
